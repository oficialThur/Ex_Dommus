# Estudos git Arthur Henrique

* **HEAD** seria um ponteira especial no git que tem a função de rastrear a sua
 localização.

* O **Blob** e um tipo de obijeto centrais que compõem o historico de commits.

* O **Commit** e o elemento central da historia do git, pois ele representa uma 
imagem do seu projeto.

* **Tree** e um objeto que reprenta a estrutura do projeto.
